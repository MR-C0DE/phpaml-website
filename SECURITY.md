# Security policy

PHPAML is currently pre-stable. Security reports should be submitted privately through GitHub Security Advisories on the affected repository. Do not open a public issue containing exploit details, credentials, or personal data.

Supported versions are the latest published CLI release and the current `main` branches of the CLI, framework, template, and website during the pre-stable period. Older pre-releases are not supported.

We aim to acknowledge critical reports within 72 hours, provide an initial assessment within 7 days, and publish a fix as soon as a safe release is available. Timelines may change when coordinated disclosure is required.

Include reproduction steps, affected version and platform, impact, and a minimal proof of concept. Never test against systems or data you do not own or have permission to access.
